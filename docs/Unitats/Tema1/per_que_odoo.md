# Odoo com a Oportunitat en DAM

Odoo és un dels ERPs més populars actualment degut a la seua flexibilitat i model de negoci.

## Versions disponibles
1. **Odoo Community**: Versió gratuïta, *on-premise*, ideal per a l'aprenentatge i xicotetes implementacions.
2. **Odoo Enterprise**: Versió de pagament amb funcionalitats avançades i suport oficial.

## Per què estudiar Odoo?
* **Cost competitiu**: Comparat amb Dynamics 365 o SAP, Odoo té una barrera d'entrada econòmica molt menor (entre 12€ i 25€ per usuari).
* **Arquitectura Modular**: Fàcil de personalitzar i estendre, una competència clau per a un desenvolupador DAM.
* **Ecosistema**: Compta amb una gran comunitat (OCA) i una tenda d'aplicacions pròpia.
